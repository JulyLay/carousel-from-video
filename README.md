```

1. Зклонуй репозиторій у ~/.claude/skills/carousel-from-video (якщо папки ~/.claude/skills немає — створи).
2. Видали з неї папку .git.
3. Перевір, що є файл ~/.claude/skills/carousel-from-video/SKILL.md.
4. Зроби все сам і коротко підтверди, що скіл встановлено.
```

Або командою в терміналі:

```bash
git clone https://github.com/JulyLay/carousel-from-video.git ~/.claude/skills/carousel-from-video && rm -rf ~/.claude/skills/carousel-from-video/.git
```
